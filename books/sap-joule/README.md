# SAP Joule

Notes for a GenAI developer building on SAP Joule: skills, agents, Joule Studio, extensibility, APIs, grounding, integration and testing. Restarted from scratch — the old book was too long and not developer-focused; activation, licensing, change management and end-user how-tos are deliberately left out.

* Source: your SAP Joule master list (128 items, tracked in `master/master.xlsx` with IDs SJ001 to SJ128).
* Laid out by topic, not by reading order: **BTP Concepts → Joule Concepts → Enabling for SuccessFactors → Joule Tutorials → Real-World Use Cases → Enabling for Other Products** (Fieldglass, Concur, etc.). Empty categories appear in the chapter menu as a placeholder for what's still to come.
* 5 chapters are written so far, across the Joule Concepts and Joule Tutorials sections — chapters are written one resource at a time and slotted into the right section as they're done. The business-user chapter is a deliberately short, trimmed exception, not a full dev-depth chapter.
* Companion book: [SAP AI](../sap-ai/README.md) (AI Core, Launchpad, Generative AI hub).
