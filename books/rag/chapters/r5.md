# Costs, errors and tests for a RAG app
> lead: The money trap of a managed vector database, the errors you will meet, and how to test a RAG app without cloud accounts.
meta: RAG | Meridian repo | 8 min read

## Why it matters

A RAG demo is cheap until a vector index is left running. The failure modes are also repetitive, so a short checklist saves hours.

## Core ideas

### Costs

:::trap Vector Search bills by the hour
Vector Search is billed **by the hour while deployed, even with no users**; it is the main cost of the whole project and the likeliest surprise bill. Delete the index when you stop, and set a budget alert (an alert does not stop spending).
:::

The Gemini API free tier has rate limits, and free-tier content may be used by Google, so upload only the sample documents. Cloud Run, Storage, Cloud Build and Secret Manager usually stay inside free allowances (the deployment chapter has the full table).

### Errors you will see

| You see | Do this |
| --- | --- |
| Searches return nothing right after upload | New data takes about a minute to become searchable |
| `DefaultCredentialsError` | `gcloud auth application-default login` |
| HTTP 503 listing missing settings | `APP_MODE=cloud` with an empty index id; fill the settings |
| Indexing or search errors after switching models | Embedding dimensions must match the index (768) |

### Testing

Tests in `backend/tests` need no cloud accounts: the model is replaced by a stand-in, so the suite runs in seconds with no key. A test that has no expected answer is only a demo, so write the expected answer first.

**What can exist in the project, and what each costs.**

| If this exists | What it means for the bill |
| --- | --- |
| An index deployed to a Vector Search endpoint | Billed **by the hour, right now**, even when nobody asks; machines stay reserved. Undeploy the index, then delete the endpoint and the index. |
| A Cloud Run service | Billed only while requests are handled (request-based billing); scaled to zero it costs nothing for compute. |
| Buckets, images in the registry, secret versions | Small storage charges; delete them when finished. |
| Only the project, with billing linked | Nothing until you create something. Deleting the project removes all of it (recoverable for 30 days). |

- **Index sizing.** Google recommends at least 2 replicas for its availability guarantee; the Meridian workflow sets no replica count, so check what yours got. The first deployment typically takes 20 to 30 minutes (the workflow waits up to 45 tries of 60 seconds). **768 dimensions** must match the embedding model.
- **Per request.** Cloud Run: one request-length of compute. Gemini: per token. An ask makes 1 model call (about 2 s); an audit makes 11 to 12 calls (about 9,000 tokens on a lite model, 18,000 on `gemini-3.8-flash`, 13 s to about 98 s). Logs hold full questions and answers, so they cost money and are sensitive.
- **A budget alert only emails.** What stops the bill is switching things off, above all the deployed index. Also remember the Cloud Build bucket `PROJECT_ID_cloudbuild` and the images when you clean up.
- **A real failure worth knowing.** Google can refuse an index deployment ("Not enough resources available") after several minutes. If the workflow carries on, the app starts without a search index and errors with "Index ... is not deployed to endpoint ...". Check `deployedIndexes` on the endpoint before uploading.
- **Cheaper for small data.** The slides note that Postgres with pgvector is simpler and cheaper than a deployed index for a small amount of text; Chroma on your laptop uses the same LangChain interface and costs nothing.
- **Free trial:** $300 for 90 days, a card that is only checked, no automatic charge; resources are deleted after a 30-day grace period (Google's Free Trial page as read on 25 Oct 2026, so check it).

## Common mistakes

| Mistake | Symptom | Fix |
| --- | --- | --- |
| Leaving Vector Search running | Surprise bill | Switch it off when done; set a budget alert |
| Uploading private documents with a free Gemini key | Content may be used by Google | Use only the sample documents |

## Interview corner

:::qa What is the biggest cost risk of deploying it?
Vector Search, billed by the hour even when idle, and possibly with two replicas by default. Do the work in one sitting, switch it off and set a budget alert (which does not stop spending).
:::
