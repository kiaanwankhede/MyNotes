# Costs, errors and tests for a RAG app
> lead: The money trap of a managed vector database, the errors you will meet, and how to test a RAG app without cloud accounts.
meta: RAG | Meridian repo | 8 min read

## Why it matters

A RAG demo is cheap until a vector index is left running. The failure modes are also repetitive, so a short checklist saves hours.

## Core ideas

### Costs

:::trap Vector Search bills by the hour
Vector Search is billed **by the hour while deployed, even with no users**; it is the main cost of the whole project and the likeliest surprise bill. Delete the index when you stop, and set a budget alert (an alert does not stop spending).
:::

The Gemini API free tier has rate limits, and free-tier content may be used by Google, so upload only the sample documents. Cloud Run, Storage, Cloud Build and Secret Manager usually stay inside free allowances (the deployment chapter has the full table).

### Errors you will see

| You see | Do this |
| --- | --- |
| Searches return nothing right after upload | New data takes about a minute to become searchable |
| `DefaultCredentialsError` | `gcloud auth application-default login` |
| HTTP 503 listing missing settings | `APP_MODE=cloud` with an empty index id; fill the settings |
| Indexing or search errors after switching models | Embedding dimensions must match the index (768) |

### Testing

Tests in `backend/tests` need no cloud accounts: the model is replaced by a stand-in, so the suite runs in seconds with no key. A test that has no expected answer is only a demo, so write the expected answer first.

## Common mistakes

| Mistake | Symptom | Fix |
| --- | --- | --- |
| Leaving Vector Search running | Surprise bill | Switch it off when done; set a budget alert |
| Uploading private documents with a free Gemini key | Content may be used by Google | Use only the sample documents |

## Interview corner

:::qa What is the biggest cost risk of deploying it?
Vector Search, billed by the hour even when idle, and possibly with two replicas by default. Do the work in one sitting, switch it off and set a budget alert (which does not stop spending).
:::
