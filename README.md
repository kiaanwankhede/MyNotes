# Agentic AI 3.0 Notes

Study notes and interview prep for the Agentic AI 3.0 course, built from the live class code, notebooks and summaries.

- `index.html` is the reader (sidebar, chapters, search, interview Q&A). Open it in a browser.
- `chapters/` holds each chapter as Markdown.
- `build/` holds the script that turns the chapters into `index.html`.

## Rebuild the reader

```bash
python3 build/build.py chapters index.html
```

## Publish as a website

Repository Settings, then Pages, then deploy from branch `main` and folder `/ (root)`.
The site will appear at `https://kiaanwankhede.github.io/MyNotes/`.
